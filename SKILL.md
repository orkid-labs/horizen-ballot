# horizen-ballot

horizen-ballot ships the Solidity contracts and artifacts for anonymous on-chain voting on Horizen Base L3. Votes are Halo2 ZK proofs — tallied on-chain without revealing ballots. Packaged as an npm dependency so integrators can import the contract sources directly.

## When to use

Building anonymous voting, governance, or polling on Horizen Base L3 or any EVM chain.

## Install

```
npm install @orkid-labs/horizen-ballot-contracts
```
